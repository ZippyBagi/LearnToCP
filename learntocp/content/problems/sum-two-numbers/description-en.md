Given two integers, print their sum.

## Input

A single line with two integers $a$ and $b$ ($-10^9 \le a, b \le 10^9$).

## Output

A single integer — the value of $a + b$.

-g> The result always fits in a 64-bit integer, so use `long long` to be safe.

-r> Reading the numbers as `int` and adding them can overflow at the extreme bounds. Don't.

## Example

```Input
2 3
```

```Output
5
```
